**Share your fusions.** Made something good? Send it to a friend.

- **Share button.** Every fusion has a Share button that saves a small `.fuseduo` file. Send it over Discord, Reddit, email, anywhere.
- **Open a shared fusion.** Double-click a `.fuseduo` file, drop it on the Fuseduo window, or use **Open shared fusion…** next to Your fusions.
- **Checked before it can run.** A shared fusion is code someone else wrote, so Fuseduo never trusts it:
  - Anything on the safety block-list (deleting files, sudo, sending messages for you) is refused and never opens.
  - Claude reads the script itself and writes the steps you see, ignoring what the sender claims. If the two don't match you get a red warning, and the risk rating goes up.
  - As always, nothing runs until you press Approve.
- **Private by design.** A shared file holds only the fusion: no icons, file paths or run history.

**Downloads:** Apple Silicon (`-mac-arm64.dmg`) or Intel (`-mac-x64.dmg`). macOS 12 or later.
The app isn't signed with a paid Apple certificate yet: the first time, right-click Fuseduo in Applications and choose **Open** (or System Settings › Privacy & Security › Open Anyway).
